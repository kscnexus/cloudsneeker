# Enterprise Backlog

Living backlog from [`enterprise-readiness.md`](enterprise-readiness.md) (assessed 2026-10-30). Order: priority, then effort. Update **Status** as work lands; add new items at the end of their priority band with the next free ID.

- **Priority:** P0 = blocks an enterprise deal or pilot on the hosted site; P1 = expected in an enterprise evaluation; P2 = differentiator or scale.
- **Effort:** S = up to 2 days, M = up to 2 weeks, L = more than 2 weeks.
- **Owner:** `Buildable` = an engineer can finish it in this repo without owner input. `Blocked: needs owner` = needs a purchase, account change, legal or pricing decision first.
- Cloudsneeker rules still apply: new code goes in `cloudsneeker_api/`, `ui/app/(cloudsneeker)/`, `ui/cloudsneeker/`, or `cloudsneeker/deploy/`; upstream files change only through recorded hooks (`upstream-hooks.md`); every item ships with tests and the deployed E2E check (`feature-verification.md`).
