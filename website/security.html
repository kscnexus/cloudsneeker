Security

How we protect your data.

A security platform has to earn trust. This page describes the controls in place today and the ones still on our roadmap.

Controls in place

Read-only cloud access In place

Cloud accounts are connected with read-only access. On AWS this is an IAM role you create in your account, based on the AWS managed SecurityAudit and ViewOnlyAccess policies, and assumed with an external ID. You can revoke it at any time.

Encrypted credentials In place

Cloud credentials and secrets you give us are encrypted by the application before they are stored.

Tenant isolation In place

Each customer's data is separated at the database level with row-level security, so one tenant's queries cannot return another tenant's records.

Access control In place

Role-based access lets you decide who can view findings, run scans or manage settings. Single sign-on with SAML is supported.

No changes without you In place

Cloud Governance runs policies as dry runs. It reports what a policy would do and does not modify your resources.

Expiring share links In place

Reports shared by link use secure links that expire, so access does not last forever.

Deploy in your account In place

For full control, the platform can be deployed inside your own AWS account so scan data stays in your environment. Available on request.

On our roadmap

We will update this page as each item is completed.

TLS on the production domain Roadmap

Serve the hosted service only over HTTPS on its production domain.

Independent penetration test Roadmap

Commission an external penetration test of the hosted service and share a summary on request.

Public status page Roadmap

Publish service status and incident history.

We do not currently hold third-party security certifications. Compliance framework mapping in the platform helps you prepare your own audits and is not a certification of Cloudsneeker or of your organisation.

Responsible disclosure

If you believe you have found a security vulnerability in Cloudsneeker, please tell us privately so we can fix it before it is disclosed.
