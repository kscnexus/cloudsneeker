Integrations are configured under **Integrations** in the web app by a user with the **manage integrations** permission. Each integration is attached to one or more providers and runs after every completed scan of those providers.

## Common behavior

- **Test connection** on each integration verifies credentials before saving.
- Integrations run inside the worker after the scan's report bundle is ready. A failed delivery does not fail the scan; the error is shown on the integration card.
- Credentials are stored encrypted with the same key as provider credentials.
- Removing an integration stops future deliveries. Nothing already delivered is removed.
